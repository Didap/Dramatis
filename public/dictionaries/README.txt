Spelling dictionaries for the editor's spell check (Hunspell format), unmodified.

it.aff, it.dic   Italian, from the npm package dictionary-it 2.0.0 (wooorm/dictionaries),
                 itself from the LibreOffice Italian dictionary. Licence: GPL-3.0, see it.LICENSE.txt.
en.aff, en.dic   English (United States), from the npm package dictionary-en 4.0.0 (SCOWL).
                 Licence: MIT and BSD, see en.LICENSE.txt.

They are data files loaded by the browser at run time, kept separate from the application code.
